# 학년별 추천 도서: 초등 5학년부터 고2까지

목표는 **논리적 사고**와 **글의 흐름을 읽는 힘**이에요. 대입 국어(독서·문학), 논술, 면접에 필요한 사고력을 학년에 맞춰 차근차근 쌓도록 골랐어요.
학년마다 **Must**(꼭 읽기) 8권과 **Better**(더 읽기) 8~11권이 있어요. 모두 126권이에요.

## 읽는 순서

한 학년에서 이렇게 읽어요.

1. **내 학년 Must**를 먼저 읽어요.
2. 다 읽으면 **한 학년 위 Must**, 그다음 **두 학년 위 Must**까지 읽어요.
3. 두 학년 위 Must까지 다 읽으면, 그때 **내 학년 Better**로 돌아와요.

Must는 생각의 뼈대(주장과 근거, 원인과 결과, 시점과 구조)를 세우는 책이라, 한 학년 위의 뼈대까지 미리 세워 두고 나서 Better로 폭을 넓혀요.
학년이 올라가면 앞에서 이미 읽은 Must는 건너뛰어요.

| 지금 학년 | 읽는 순서 |
|---|---|
| 초5 | 1단계 **초5 Must** → 2단계 **초6 Must** → 3단계 **중1 Must** → 4단계 **초5 Better** |
| 초6 | 1단계 **초6 Must** → 2단계 **중1 Must** → 3단계 **중2 Must** → 4단계 **초6 Better** |
| 중1 | 1단계 **중1 Must** → 2단계 **중2 Must** → 3단계 **중3 Must** → 4단계 **중1 Better** |
| 중2 | 1단계 **중2 Must** → 2단계 **중3 Must** → 3단계 **고1 Must** → 4단계 **중2 Better** |
| 중3 | 1단계 **중3 Must** → 2단계 **고1 Must** → 3단계 **고2 Must** → 4단계 **중3 Better** |
| 고1 | 1단계 **고1 Must** → 2단계 **고2 Must** → 3단계 **고1 Better** |
| 고2 | 1단계 **고2 Must** → 2단계 **고2 Better** |

목록은 대입 전인 고2에서 끝나요. 그래서 고1은 고2 Must까지, 고2는 내 학년 Must 다음에 바로 Better로 가요.

### 지금 초5라면

1. 초5 Must 8권: 마당을 나온 암탉 → 논리야, 놀자 → 수학 귀신 → …
2. 초6 Must 8권: 어린 왕자 → 반갑다 논리야 → 생각한다는 것 → …
3. 중1 Must 8권: 아몬드 → 동물농장 → 소피의 세계 → …
4. 초5 Better 10권

중1 Must는 초5에게 어려울 수 있어요. 한 권을 읽는 데 오래 걸려도 괜찮고, 보호자와 같이 읽거나 한 장씩 이야기를 나누며 읽어요.
6학년이 되면 초6 Must는 이미 읽었으니, 중2 Must를 읽고 초6 Better로 넘어가요.

## 사고력을 키우는 읽기 습관

책을 다 읽으면 세 가지만 짧게 적어요. 이 사이트의 독서 확인 퀴즈와 구조 그리기도 같은 연습이에요.

- **한 문장 요약**: 이 책(또는 이 장)이 말하려는 것은 무엇인가요?
- **근거 셋**: 그렇게 생각한 이유를 책 속 장면이나 문장에서 세 개 찾아요.
- **반대로 묻기**: 작가나 인물의 생각에 동의하지 않는다면, 무엇을 근거로 반박할까요?

초등은 이야기 산(발단–전개–위기–절정–결말)으로, 중학교부터는 주장–근거–반론–재반론으로 구조를 그려 보면 좋아요.
